# Midterm project — your work goes here

Create a directory named after your GitHub handle and work inside it:

```
labs/midterm/<your-github-handle>/
├── README.md          project overview, how to run
├── report.pdf         IMRaD report, 4–6 pages
├── code/              data_generation/, training/, analysis/, checkpoints/
├── data/              dataset, or instructions to regenerate it
├── figures/
├── slurm_logs/
└── prompts.md         agent prompt log + the reflection paragraph (see the spec)
```

The full specification, the three flavors, and the rubric are in `module_4/homework/midterm_project_spec.md`.
Keep large files out of git (GitHub rejects files over 100 MB).
Submit by opening a pull request from a branch named `midterm`. Due Sun Nov 8, 11:59 PM Mountain (extended from Sun Nov 1).
